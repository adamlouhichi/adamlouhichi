### 🌤️ Prévision météorologique avec Deep Learning

> *Projet académique | Analyse de séries temporelles*

Étude comparative de différentes architectures de réseaux de neurones pour la prévision de température.

**Architectures étudiées :**

* **RNN simple** – modèle de référence
* **LSTM univarié** – prédiction à une étape
* **LSTM empilé multivarié** – prédiction multi-étapes à partir de plusieurs variables météorologiques

**Résultats – MAE sur l'ensemble de test :**

* RNN simple : 2,8 °C
* LSTM univarié : 1,9 °C
* LSTM empilé multivarié : 1,2 °C
